# Welcome

This is **JustAGuest's Script Repository**.

## Loading Scripts

To load a script from this repository, use:

```luau
loadstring(game:HttpGet("https://raw.githubusercontent.com/JustSomeGuest/Scripts/main/Init.luau"))()

Init.ScriptName()
```

Replace `ScriptName` with the name of the script you want to run.

## Available Scripts

All available scripts are listed in [`Init.luau`](./Init.luau).

Check the `Scripts` table to see the names you can use with `Init.ScriptName()`.
